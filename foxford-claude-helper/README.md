# Claude AI для Foxford

Расширение Google Chrome (Manifest V3), которое помогает разобраться в заданиях на
[foxford.ru](https://foxford.ru): анализирует текст задания, определяет вопрос и варианты
ответа, отправляет их в Claude API и показывает предполагаемый ответ с объяснением
простыми словами и уровнем уверенности.

## Возможности

- Работает **только** на страницах `foxford.ru` (и поддоменах).
- Плавающая кнопка «Claude AI» справа на странице.
- Автоматический разбор текста задания и вариантов ответа.
- Панель с результатом: ответ, объяснение, шкала уверенности, кнопка «Объяснить подробнее».
- Снимок видимой области вкладки и отправка изображения вместе с вопросом (для графиков,
  формул и картинок). Панель расширения на снимок не попадает.
- Тёмная и светлая тема (плюс режим «как в системе»), интерфейс полностью на русском.
- **Расширение никогда не нажимает кнопку отправки или сдачи задания.**

## Установка

1. Скачайте или распакуйте папку `foxford-claude-helper` (или архив `foxford-claude-helper.zip`).
2. Откройте `chrome://extensions`.
3. Включите **Режим разработчика** (переключатель справа сверху).
4. Нажмите **Загрузить распакованное расширение** и выберите папку `foxford-claude-helper`.
5. При первой установке автоматически откроется страница настроек — введите API-ключ.

## Настройка API-ключа

1. Создайте ключ в консоли Anthropic: <https://console.anthropic.com> → **API Keys**.
2. Откройте настройки расширения (иконка расширения → «Настройки и API-ключ»).
3. Вставьте ключ вида `sk-ant-…`, нажмите **Сохранить**, затем **Проверить ключ**.

Ключ хранится в `chrome.storage.local` на вашем компьютере и **не содержится в исходном коде**.
Запросы уходят напрямую с вашего браузера в `https://api.anthropic.com`, промежуточных
серверов нет. Кнопка «Удалить ключ» полностью стирает его из хранилища.

## Использование

1. Откройте страницу с заданием на foxford.ru.
2. Нажмите плавающую кнопку **«Claude AI»** справа (или иконку расширения → «Разобрать задание»).
3. Расширение соберёт текст задания и покажет панель с ответом.
4. Если в задании есть картинка или график, включите галочку **«Прикрепить снимок экрана»**
   и нажмите **«Анализировать»** — вместе с текстом отправится снимок видимой области.
5. Кнопка **«Объяснить подробнее»** запрашивает развёрнутое пошаговое объяснение.
6. Кнопка **◐** в шапке панели переключает тему: авто → светлая → тёмная.

Выделите фрагмент текста на странице перед нажатием кнопки, если автоопределение
задания сработало неточно — выделение имеет приоритет.

## Структура проекта

```
foxford-claude-helper/
├── manifest.json          # Manifest V3, permissions и host_permissions
├── background.js          # service worker: запросы к Claude API, скриншот вкладки
├── content.js             # плавающая кнопка, разбор задания, панель результата
├── styles.css             # стили внутристраничного интерфейса (тёмная/светлая тема)
├── ui.css                 # стили popup и страницы настроек
├── popup.html / popup.js  # меню расширения: статус, тема, быстрый запуск
├── options.html / options.js # ввод и проверка API-ключа, модель, лимит токенов
├── _locales/ru/messages.json
├── icons/                 # иконки 16/48/128
└── README.md
```

## Разрешения и зачем они нужны

| Разрешение | Назначение |
|---|---|
| `storage` | хранение API-ключа, модели и темы локально |
| `activeTab` | доступ к активной вкладке для снимка видимой области |
| `scripting` | резервный запуск логики на текущей вкладке |
| `host_permissions: foxford.ru` | внедрение кнопки и чтение текста задания |
| `host_permissions: api.anthropic.com` | прямые запросы к Claude API из service worker |

## Модели

По умолчанию используется `claude-sonnet-5`. В настройках можно выбрать
`claude-opus-5` (качественнее) или `claude-haiku-4-5-20251001` (быстрее и дешевле).

## Ограничения и честное предупреждение

- Ответы генерирует ИИ — они могут быть неверными. Проверяйте их перед отправкой.
- Расширение задумано как помощник для понимания материала, а не как способ обойти
  самостоятельную работу; отправку ответа вы всегда выполняете вручную.
- Вёрстка Foxford меняется — если задание не распозналось, выделите его текст мышью
  или используйте снимок экрана.

## Приватность

Расширение не собирает статистику, не имеет своего сервера и не передаёт данные никуда,
кроме `api.anthropic.com`. Отправляются только текст текущего задания и, по вашему
явному выбору, снимок видимой области вкладки.
