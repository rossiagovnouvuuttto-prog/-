Настройки Claude AI для Foxford

API-ключ Claude

Ключ создаётся в консоли Anthropic (console.anthropic.com → API Keys) и хранится только в локальном хранилище браузера. В коде расширения ключа нет.

Модель и ответ

Как это работает

  • Расширение активно только на страницах foxford.ru.
  • Текст задания и (по желанию) снимок видимой области отправляются в Claude API напрямую с вашего компьютера.
  • Расширение никогда не нажимает кнопку отправки или сдачи задания.
  • Ответ ИИ может быть неверным — проверяйте его самостоятельно.
