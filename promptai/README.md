# PromptAI

Генератор промптов для AI-изображений. Пользователь описывает идею обычными
словами — сервис превращает описание в профессиональный английский промпт для
Midjourney, Stable Diffusion, DALL·E, Flux и других генераторов.

Тёмная тема, градиенты, плавные анимации, mobile-first вёрстка.
Ни одной внешней зависимости: чистый HTML, CSS и ES-модули.

---

## Запуск

### Просто посмотреть сайт

Скачайте **`promptai.html`** и откройте его двойным кликом. Это автономная
сборка: весь CSS и JavaScript внутри одного файла, ничего устанавливать и
запускать не нужно, интернет не требуется.

### Для разработки

Исходники разбиты на ES-модули, поэтому `index.html` нужно открывать через
HTTP — с диска браузер модули заблокирует.

```bash
cd promptai

# любой из вариантов
python3 -m http.server 4173
npx http-server -p 4173 .
```

Затем откройте <http://localhost:4173>.

После изменений в `assets/` пересоберите автономную версию:

```bash
node build.mjs     # index.html + assets/ → promptai.html
```

Для публикации подойдёт любой статический хостинг: GitHub Pages, Netlify,
Vercel, Cloudflare Pages, обычный nginx.

## Как собирается промпт

Промпт всегда строится по одной структуре — так работают профессиональные
промпт-инженеры:

```
Объект изображения + Стиль + Окружение + Камера + Освещение + Качество + Детализация
```

Пример для запроса «футуристический город с летающими машинами»
(стиль «Киберпанк», камера Cinematic, свет Neon lights, качество 8K, формат 16:9):

```
a futuristic city with flying cars,
cyberpunk style, futuristic dystopia,
rainy streets with neon lights,
cinematic camera angle, anamorphic wide shot,
neon lights, volumetric lighting, colored reflections,
8K detail, ultra high resolution,
ultra detailed, reflections and wet surfaces, chromatic aberration,
wide 16:9 composition
```

Дополнительно карточка результата отдаёт negative prompt стиля и параметр
соотношения сторон для Midjourney (`--ar 16:9`).

## Перевод промпта обратно на русский

Кнопка «Перевести на русский» показывает под карточкой, что написано в
промпте. Сам промпт при этом не меняется — копируется и уходит в генератор
английский текст.

Перевод не пословный: промпт собирается из известного набора формулировок,
поэтому для каждой из них в `data/fragments-ru.js` лежит готовый русский
вариант. Первая строка берётся прямо из описания пользователя, если оно было
на русском. Для описания, введённого по-английски, работает обратный словарь
с согласованием прилагательных по роду и числу.

Полнота набора проверяется тестом — он обходит все стили, настройки, варианты
и улучшения и падает, если хоть один фрагмент остался без перевода:

```bash
npm test                      # то же, что node tests/fragments.test.mjs
node tests/ollama.test.mjs    # проверка запросов к Ollama, без настоящего ключа
```

## Подключение настоящего AI

По умолчанию работает встроенный движок — сайт полностью функционален без сети
и без ключей. Чтобы промпты писала настоящая модель, есть два пути.

### Способ 1. Вставить ключ прямо на сайте

1. Откройте <https://ollama.com/settings/keys>, нажмите **Add API Key**, скопируйте ключ.
2. На сайте под полем ввода нажмите **«Подключить свой AI»**.
3. Вставьте ключ, нажмите **«Проверить и подключить»**.

Ключ сохраняется только в localStorage вашего браузера: в код сайта он не
попадает, в репозиторий тоже, другим посетителям не виден. Отправляется он
единственному адресату — самой Ollama.

Сработает это лишь в том случае, если Ollama разрешает обращения со страниц
сайтов (CORS). Если браузер запрос не пропустит, окно так и напишет — тогда
переходите ко второму способу. Тем же окном подключается и Ollama,
установленная на вашем компьютере.

### Способ 2. Запустить сервер

Работает всегда: запрос в Ollama делает сервер, а не браузер, и правила CORS
к нему не применяются.

1. Скопируйте `.env.example` в `.env` и вставьте ключ:

   ```
   OLLAMA_API_KEY=ваш_ключ
   OLLAMA_MODEL=gpt-oss:120b-cloud
   ```

   Файл `.env` внесён в `.gitignore` — в репозиторий он не попадёт.

2. Запустите:

   ```bash
   cd promptai
   npm start
   ```

3. Откройте <http://localhost:4173>.

При старте сервер сам проверит связь и напишет, подключилась модель или нет.
Нужен установленный [Node.js](https://nodejs.org) версии 18 или новее.

### Локальная Ollama вместо облака

Если Ollama установлена на этом же компьютере, ключ не нужен совсем — просто
запустите сервер без `.env`, он сам обратится к `http://localhost:11434`.
Модель задаётся переменной `OLLAMA_MODEL` (по умолчанию `llama3.2`).

### Что делает сервер

| Адрес | Назначение |
|---|---|
| `GET /api/health` | режим, адрес и модель — по нему сайт понимает, что AI доступен |
| `POST /api/prompt` | генерация, улучшение, варианты и переводы |
| всё остальное | статические файлы сайта |

Сервер просит модель заполнить поля `subject`, `style`, `environment`,
`camera`, `lighting`, `quality`, `detail`, `format` и `negative` через
JSON-схему Ollama. Поэтому структура промпта сохраняется даже при смене
модели, а ответ не приходится разбирать из свободного текста.

Если Ollama недоступна или в ключе ошибка, сервер отвечает кодом 502 с
понятным текстом, а сайт молча возвращается на встроенный движок — страница
продолжает работать.

### Свой бэкенд вместо нашего

Сайт не привязан к Ollama: подойдёт любой сервер с тем же контрактом.
Режим выбирается в `assets/js/config.js`:

```js
export const AI = {
  provider: 'auto',           // 'auto' | 'local' | 'api'
  endpoint: '/api/prompt',
  healthEndpoint: '/api/health',
  fallbackToLocal: true,
};
```

`auto` — сайт сам проверяет, отвечает ли бэкенд, и если нет, считает локально.

### Контракт эндпоинта

**Запрос**

```json
{
  "task": "generate",
  "idea": "футуристический город с летающими машинами",
  "settings": {
    "style": "cyberpunk",
    "camera": "cinematic",
    "lighting": "neon",
    "quality": "8k",
    "aspect": "16:9"
  }
}
```

`task` принимает значения `generate`, `improve`, `variants`, `translate`,
`translate-ru`. Для `improve` дополнительно приходит `prompt` и `multiline`,
для `variants` — `count`, для `translate` — `text`, для `translate-ru` —
`text` и `idea`.

**Ответ**

```json
{
  "prompt": "a futuristic city with flying cars, cyberpunk style, ...",
  "multiline": "a futuristic city with flying cars,\ncyberpunk style, ...",
  "negative": "daylight, rustic, medieval, low contrast, watermark",
  "ratio": "--ar 16:9"
}
```

Для `variants` — `{ "variants": [{ "name": "Драматичный", "prompt": "..." }] }`,
для `translate` и `translate-ru` — `{ "text": "..." }`.

## Тарифы и лимиты

Настраиваются в `assets/js/config.js` → `PLANS`:

| Тариф   | Генераций в сутки | Вариантов за раз |
|---------|-------------------|------------------|
| Гость   | 5                 | 2                |
| Free    | 20                | 3                |
| Premium | без ограничений   | 5                |

Расход считается отдельно для гостя и для каждого аккаунта, счётчик
обнуляется каждые сутки.

## Аккаунты

`auth.js` содержит демонстрационный провайдер: аккаунты лежат в localStorage,
пароль хранится как SHA-256 с солью. Этого достаточно для демонстрации
сценария, но **это не боевая авторизация** — она невозможна без сервера.

Чтобы подключить настоящую авторизацию, реализуйте те же методы
(`register`, `login`, `logout`, `current`, `setPlan`) поверх своего API и
подставьте объект в экспорт `auth`. Остальной код менять не придётся.

То же касается оплаты Premium: сейчас тариф переключается кнопкой, на проде
сюда приходит вебхук платёжной системы.

## Хранение данных

История (до 60 записей), избранное (до 120), настройки, аккаунты и счётчик
генераций хранятся в `localStorage` под префиксом `promptai:v1:`.
Если localStorage недоступен (приватный режим), данные живут в памяти вкладки.

Chrome / Edge 90+, Safari 16+, Firefox 90+, мобильные Chrome и Safari.
