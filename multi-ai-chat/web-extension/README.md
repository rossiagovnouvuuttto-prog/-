# Multi AI Chat — ChatGPT + DeepSeek Web

Версия 2.3.1.

Исправления v2.3.1:
- Служебные сообщения Chrome («Frame with ID 0 is showing error page») больше не попадают в чат. Каждый сбой внедрения скрипта переводится в понятную фразу: сайт не открылся, нужен вход, нет доступа.
- Загрузка страницы проверяется по адресу, а не только по статусу «complete»: страница ошибки Chrome и редирект на форму входа теперь различаются и называются своими словами.
- Ошибка без известного кода не показывается как есть — в чат идёт общая фраза, а подробности уходят в консоль расширения.
- Свои модели снова читаются из хранилища при запуске (строка `customModels` в app.js теряла сохранённый список).
- Добавлен тест `tests/test_web_extension.py`: расширение грузится в настоящий Chromium и проверяется, что при недоступном сайте в чате оказывается человеческий текст.

Исправления v2.3:
- Убрана предзагрузка ChatGPT/DeepSeek при открытии Multi AI Chat: сайт больше не открывается сам по себе до первого запроса.
- Вместо двух конкурирующих служебных вкладок используется одно служебное окно и одна вкладка. Это устраняет путаницу, когда вкладка называлась DeepSeek, а внутри оказывался ChatGPT.
- Добавлена защита от появления служебного окна поверх Multi AI Chat: окно создаётся свёрнутым, повторно сворачивается во время загрузки и при случайном получении фокуса.
- Убрано постоянное переключение active-tab каждые 1.2 секунды, из-за которого Chrome на некоторых Windows-сборках восстанавливал служебное окно.
- Перед отправкой расширение теперь проверяет, что текст действительно появился в поле ChatGPT/DeepSeek.
- После отправки отдельно проверяется, что поле очистилось, началась генерация или появился новый ответ. Если сайт не принял сообщение, возвращается точная ошибка, а не «пустой ответ».
- Усилены селекторы текущих редакторов ChatGPT/DeepSeek и отправки через кнопку/форму/Enter.
- Ответ определяется только как новый относительно состояния страницы до отправки, поэтому старые сообщения и элементы интерфейса не принимаются за ответ.
- Пустой результат по-прежнему никогда не считается успешным.

Использование:
1. В этом же профиле Chrome войдите на chatgpt.com и chat.deepseek.com.
2. Отключите предыдущую версию расширения.
3. chrome://extensions → Режим разработчика → Загрузить распакованное.
4. Откройте Multi AI Chat, выберите ChatGPT или DeepSeek и отправьте сообщение.

Служебное окно не должно оставаться поверх чата. Если сайт реально изменит DOM, расширение покажет конкретно «не найдено поле», «не удалось вставить» или «сообщение не отправилось», вместо ложного пустого ответа.
