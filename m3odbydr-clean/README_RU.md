# m3odbydr!! — Fabric 1.21.11

Чистый клиентский мод, написанный с нуля и не использующий исходники ABOBUS123.

Функции:
- Right Shift — LiveGUI
- C — Zoom
- F7 — HUD
- F8 — SuperRes Lite / FPS preset
- Left Alt — Freelook
- B — Fullbright
- Sprint включён по умолчанию
- HUD: FPS, XYZ, ping
- Drag & Drop для LiveGUI
- Темы: Crystall Glow, Neon Cyan, Sunset Gradient, Dark Gray

Требования: Minecraft 1.21.11, Fabric Loader 0.18.1+, Fabric API 0.141.6+1.21.11, Java 21.
